Preguntas frecuentes

Lo que conviene saber antes de empezar.

¿Qué puede incluir una web para una constructora?

Portafolio de obras, servicios, información empresarial, botones de WhatsApp y formularios. El alcance final depende de lo que realmente necesites.

¿Voy a poder agregar obras nuevas?

Podemos incluir un plan de mantenimiento para actualizar proyectos y fotografías o un panel para gestionar contenidos, según el presupuesto.

¿Cómo se define el precio?

Primero revisamos objetivos, material y funcionalidades. Después presentamos una propuesta con alcance y precio detallados.
